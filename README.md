# AssetFlow — ระบบบริหารจัดการสถานที่และครุภัณฑ์ (Standalone Version)

ระบบบริหารจัดการสถานที่จัดเก็บและทะเบียนครุภัณฑ์แบบเน้นรูปภาพ (Visual Asset & Location Directory Management System) เวอร์ชัน **Standalone** สำหรับรันในเครื่องหรือเครือข่ายภายใน (Local Intranet) โดยไม่ต้องพึ่งพาเซิร์ฟเวอร์ภายนอกหรือคลาวด์

---

## 🌟 ฟังก์ชันเด่นของระบบ

1. **📍 ทะเบียนพิกัดสถานที่จัดเก็บ (Location Directory):**
   - บันทึกและจัดหมวดหมู่สถานที่จัดเก็บ (เช่น จวนผู้ว่าฯ, ศาลากลาง, ห้อง IT)
   - จัดการข้อมูลสถานที่ (CRUD: เพิ่ม แก้ไข ลบ) พร้อมระบบนับจำนวนครุภัณฑ์ในแต่ละพิกัดอัตโนมัติ

2. **🖼️ แคตตาล็อกรูปภาพครุภัณฑ์และวัตถุมงคล (Visual Asset Catalog):**
   - แสดงผลภาพครุภัณฑ์/วัตถุมงคลเต็มใบ 100% คมชัด ไม่มี Badge ลอยบังภาพ
   - ระบบค้นหาและตัวกรองตามรหัสพัสดุ, ชื่อ, Serial Number, หมวดหมู่ และสถานที่
   - ระบบพิมพ์ **ใบตรวจนับพัสดุประจำปี (Print Checklist A4)** พร้อมช่องติ๊ก [ ] ปกติ [ ] ชำรุด [ ] สูญหาย และ Export ข้อมูลเป็น CSV

3. **👥 การดูแลผู้ใช้งานและสิทธิ์ (User & Access Control):**
   - จัดการผู้ใช้แยกตามบทบาท (Admin, Officer, Approver, Staff)
   - ระบบความปลอดภัยรหัสผ่าน PBKDF2 (SHA-256) และระบบเปลี่ยนรหัสผ่าน

4. **💾 รองรับทั้ง Local Mode และ Free Cloud Mode (Supabase + Cloudinary):**
   - **Local Mode (เริ่มต้น):** ฐานข้อมูลบันทึกใน `assetflow.db` (SQLite) และรูปภาพบันทึกใน `public/uploads/`
   - **Cloud Mode (แนะนำสำหรับหลายเครื่อง):** เชื่อมต่อกับ **Supabase (PostgreSQL)** และ **Cloudinary** เพื่อซิงค์ข้อมูลและรูปภาพแบบเรียลไทม์ 24 ชม. ฟรี 100% (ดูวิธีตั้งค่าใน [`SUPABASE_CLOUDINARY_GUIDE.md`](./SUPABASE_CLOUDINARY_GUIDE.md))

## 🚀 วิธีการเริ่มใช้งาน (Quick Start)

### วิธีที่ 1: ดับเบิลคลิกเปิดใช้งานทันที (Windows)
ดับเบิลคลิกไฟล์ **`start.bat`**
- ระบบจะทำการติดตั้งแพ็กเกจที่จำเป็น (ในครั้งแรก)
- เริ่มต้นสร้างฐานข้อมูล SQLite และนำเข้าข้อมูลจริงอัตโนมัติ
- เปิดเบราว์เซอร์เข้าสู่ระบบที่ `http://localhost:3000`

### วิธีที่ 2: รันผ่าน Terminal / PowerShell
```powershell
# 1. ติดตั้ง Dependencies
npm install

# 2. เริ่มต้นรันระบบ
npm run dev
```

## 📁 การสำรองข้อมูล (Data Backup)

เพื่อความปลอดภัยของข้อมูล คุณสามารถสำรองข้อมูลได้ง่ายๆ เพียงคัดลอกไฟล์/โฟลเดอร์ต่อไปนี้:
- **`assetflow.db`** (ไฟล์ฐานข้อมูลหลักทั้งหมด)
- **`public/uploads/`** (ไฟล์เอกสารและรูปภาพที่อัปโหลดเพิ่ม)
- **`public/images/`** (รูปภาพครุภัณฑ์ตั้งต้น)
